# homepage
This homepage began as simple HTML, CSS, and Javascript written in Notepad.  After building the structure, I used the small LLM Phi4, locally run on my machine in the cmd prompt with Ollama, to enhance the code. I tried a blue theme, but favor white themes and went with a white background and card style. At this point I was using VS Code with the Prettier extension and committing directly to GitHub instead of using GitHub Descktop. I was unable to get my hero images to transition gradually on hover, though. The change was very abrupt, and I knew that I needed code I didn't yet understand. I used the much more powerful ChatGPT5+ to analyse my code as a txt file and improve its style with specific prompts for icon buttons, image shifts, color gradients etc. I changed a few things to make it more visually appealing and functional. I am still studying the the ChatGPT5+ generated CSS code and am learning a lot. The dancers image, reused here, is one I drew decades ago for a ballroom dance business that I own.
